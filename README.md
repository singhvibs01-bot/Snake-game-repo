# AI PM Portfolio: Mini Browser Game Projects

This repository is a lightweight portfolio-style sandbox built to demonstrate product thinking, rapid prototyping, and browser-based interaction design. It contains small childhood-game concepts implemented as standalone HTML games using simple front-end technologies.

The purpose is not just to build games, but to showcase how an AI product manager can prototype user experiences quickly, validate features, write product requirements, and iterate on feedback with minimal setup.

## Portfolio Purpose

This repo represents an AI PM portfolio project that highlights:

- rapid product prototyping with HTML, CSS, and JavaScript
- user-centered design thinking
- feature ideation and PRD writing
- accessibility and UX polish
- responsive UI design
- iteration based on testing and feedback
- lightweight, no-dependency execution

In other words, this project is a practical portfolio artifact showing how product concepts can be turned into working prototypes quickly.

## Included Games

### 1. Memory Game
A classic card-matching game built as a clean single-page browser app.

Features:
- 4x4 and 6x6 board sizes
- move tracking and time tracking
- star rating feedback
- local best-score persistence
- keyboard-friendly interaction
- accessible UI and responsive design
- dark theme toggle support

This demonstrates product polish, UX improvements, and iterative experimentation.

### 2. Snake Game
A classic arcade Snake prototype designed for the same lightweight browser-only approach.

Features:
- keyboard movement controls
- score and best-score tracking
- pause and restart flow
- collision detection and game-over states
- responsive board layout
- single-file execution without dependencies

This shows functional game loop design and basic gameplay flow in a small and testable format.

## How to Run

### Option 1: Open files directly
Open the following files in a browser:
- `memory-game.html`
- `snake-game.html`

### Option 2: Run a local server
From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

- http://localhost:8000/memory-game.html
- http://localhost:8000/snake-game.html
